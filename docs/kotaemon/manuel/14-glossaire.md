# 14. Glossaire

> Ce chapitre renvoie au glossaire de la série et rappelle les mots propres à Kotaemon.
> **Point de départ** : aucun ; ce chapitre se lit sans l'application.
> **Durée** : environ 5 minutes. **Avant** : aucun.

## Ce qu'il faut savoir

Les mots techniques employés dans ce manuel sont définis simplement dans le [glossaire de la série](../../glossaire.md), commun à tous les manuels. Le tableau ci-dessous reprend les mots que l'interface de Kotaemon affiche en anglais, avec leur sens.

## Mots de l'interface

| Libellé de l'interface | Sens |
|---|---|
| « Chat » | onglet des conversations : poser des questions, lire les réponses et leurs sources |
| « Files » | onglet des documents, un sous-onglet par collection |
| « Resources » | onglet de l'administrateur : collections, modèles, serveurs MCP, comptes |
| « Settings » | réglages du compte : mot de passe, recherche, rédaction des réponses |
| « Help » | aide en ligne et notes de version |
| « Upload and Index » | envoyer les fichiers choisis et les indexer |
| « Search All », « Search In File(s) » | chercher dans toute la collection, ou dans les fichiers et groupes choisis |
| « Information panel » | panneau des passages cités |
| « Relevance score » | note de pertinence d'un passage |
| « Chat settings » | réglages de la conversation en cours : méthode, modèle, langue |
| « Reasoning method » | méthode de raisonnement : `simple`, `complex`, `ReAct`, `ReWOO` |
| « Mindmap » | carte mentale de la réponse |
| « citation: highlight », « citation: inline », « no citation » | style des citations : passages surlignés dans le panneau, renvois dans le texte, aucune |
| « File loader » | lecteur de fichiers utilisé pour les PDF |
| « Number of document chunks to retrieve » | nombre de passages transmis au modèle |
| « Retrieval mode » | mode de recherche : par le sens (`vector`), par les mots (`text`) ou les deux (`hybrid`) |
| « Use reranking » | trier les passages avec le modèle de tri |
| « Use LLM relevant scoring » | faire noter chaque passage par le modèle de réponse |
| « Max context length (LLM) » | quantité maximale de texte des documents envoyée au modèle |
| « Set default » | faire d'un modèle celui utilisé par défaut |
| « Test connection » | vérifier qu'un modèle répond |
| « Force reindex file » | relire et réindexer un fichier déjà présent |

## Résultat

Le lecteur retrouve le sens de chaque libellé anglais de l'interface.
